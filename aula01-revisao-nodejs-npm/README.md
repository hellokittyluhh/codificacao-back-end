Hoje, na Sala 01, realizei uma revisão dos conceitos de "Node.js e NPM". Criei e configurei um projeto utilizando "CommonJS", trabalhando com o módulo nativo `os` do Node.js. Desenvolvi um diagnóstico do servidor para obter informações como "arquitetura do sistema operacional, memória RAM total e disponível, quantidade de núcleos do processador, modelo e velocidade do processador". Foi uma atividade importante para praticar a utilização de módulos nativos e a coleta de informações do sistema.
