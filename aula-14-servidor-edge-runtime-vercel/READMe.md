## 📚 Comentário sobre a aula

Na aula de hoje, aprendemos sobre o **Vercel Edge Runtime** e como ele pode ser utilizado para executar funções de uma aplicação de forma distribuída. A proposta do Edge Runtime é permitir que o código seja executado em uma infraestrutura mais próxima do usuário, o que pode ajudar a diminuir a latência e melhorar o tempo de resposta das aplicações.

Durante a aula, configuramos uma API para utilizar o ambiente `edge` e criamos uma função capaz de retornar algumas informações relacionadas à sua execução. Entre essas informações estão a mensagem retornada pela API, o horário do servidor, a região em que a função foi executada e o tempo necessário para realizar a execução. Com isso, conseguimos observar na prática que uma função pode ser executada em diferentes regiões e que essas informações podem ser utilizadas para analisar o comportamento da aplicação.

Também aprendemos a utilizar a **Vercel CLI**, que permite controlar e gerenciar projetos da Vercel através do terminal. Fizemos a instalação da ferramenta e realizamos o processo de login para conectar o ambiente de desenvolvimento com a nossa conta da Vercel. A partir disso, entendemos melhor como preparar um projeto para ser enviado para a plataforma e disponibilizado na internet.

Outro ponto importante da aula foi entender melhor a diferença entre executar uma aplicação **localmente** e executar uma aplicação em um ambiente de **produção na nuvem**. Enquanto durante o desenvolvimento podemos testar nossa API diretamente no computador, com o deploy conseguimos disponibilizar essa aplicação para que ela possa ser acessada de outros lugares.

No geral, a aula foi bastante importante para entender conceitos de **deploy, APIs, Edge Functions, Vercel, execução distribuída e desempenho**. Além da parte teórica, a prática ajudou a visualizar como essas ferramentas são utilizadas em projetos reais e como podemos utilizar a Vercel para facilitar o processo de publicação e execução das nossas aplicações. 🚀
