Ontem trabalhei na criação de um gerador de logs utilizando Node.js e Streams. Implementei a geração de um arquivo de log com uma grande quantidade de linhas, alternando entre mensagens de INFO e ERROR, com o objetivo de simular um cenário real de processamento de logs.
Hoje dei continuidade trabalhando no processamento desse arquivo utilizando ReadStream e readline. Implementei um filtro para identificar e separar as linhas que possuem ERROR, além de contabilizar a quantidade de erros encontrados. Também acompanhei o consumo de memória durante o processamento para entender a vantagem do uso de Streams em arquivos grandes.
